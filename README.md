# 🏃 InfinitRun CM

> **Jogo 2D de corrida infinita desenvolvido na Unity como projeto acadêmico para a matéria de Desenvolvimento de Jogos.**

---

## 📖 Sobre o Projeto

**InfinitRun CM** é um jogo de corrida infinita (*infinite runner*) em 2D desenvolvido na engine **Unity**, utilizando **C#** como linguagem principal. O jogador controla um personagem que corre automaticamente por um cenário gerado proceduralmente, desviando de obstáculos e acumulando pontuação ao longo do tempo.

O projeto foi desenvolvido como trabalho acadêmico para a disciplina de **Desenvolvimento de Jogos**.

---

## 🎮 Como Jogar

- O personagem corre automaticamente da esquerda para a direita
- Use os controles para **pular** ou **desviar** dos obstáculos
- Sobreviva o máximo de tempo possível para aumentar sua pontuação
- O jogo fica progressivamente mais difícil com o passar do tempo

## 📋 Pré-requisitos

Para abrir e rodar o projeto localmente, você precisará de:

- [Unity Hub](https://unity.com/download) instalado
- Unity **2021.3 LTS** ou superior (recomendado)
- Visual Studio ou VS Code com extensão C#

---

## 🚀 Como Executar o Projeto

```bash
# 1. Clone o repositório
git clone https://github.com/ClaudioMatheusDev/InfinitRunCM.git

# 2. Abra o Unity Hub

# 3. Clique em "Add" e selecione a pasta do projeto clonado

# 4. Abra o projeto e aguarde a importação dos assets

# 5. Abra a cena principal e clique em Play
```

---

## 📁 Estrutura do Projeto
